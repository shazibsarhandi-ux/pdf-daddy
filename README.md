# PDF Daddy

A PDF editor that runs in your browser: view, edit, organise, comment, fill and sign, protect and compare PDFs, in English, Arabic or Urdu.

**Open it: https://shazibsarhandi-ux.github.io/pdf-daddy/**

Your files never leave your computer: every PDF is opened, edited and saved inside your browser.

This repository holds the built website only. PDF Daddy uses MuPDF, which is licensed under the GNU AGPL, so the complete source code of this version is offered from the app itself (app menu › Download Source Code).
